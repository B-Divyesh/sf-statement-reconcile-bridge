# Demo sandbox

Open `/demo` or use **Try it with sample data**. It loads ten realistic
April 2026 coffee-shop, grocery, utility, transport, and bookshop statement
records with an eleven-row private ledger. The sample starts in the isolated
`demo:statement-reconcile-bridge:` localStorage namespace. The visible demo
banner offers **Reset demo** and **Start for real**. Reset replaces only that
namespace. Leaving through any navigation discards it. Starting for real switches to the separate
`real:statement-reconcile-bridge:` namespace.

The demo is bundled with the app shell, so it can be used after a first online
visit when offline.
